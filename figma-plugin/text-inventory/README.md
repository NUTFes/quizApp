# QuizApp Text Inventory

選択した画面フレーム配下のテキストを読み取り、**タイポグラフィの現状**を一覧にする読み取り専用プラグインです。

Figma には `Selection colors` の文字版がありません。複数のテキストを選んでも `Mixed` と出るだけで、「どのスタイルが何件使われているか」「スタイルが当たっていないテキストはどれか」を見る方法がない。それを埋めるためのものです。

Issue #52（色・フォントのトークン定義）で、フォントのスケールを決める材料に使います。

## 何が分かるか

| 出力 | 何のために見るか |
| --- | --- |
| **使われているスタイル** | 実際に機能しているスタイルはどれか |
| **スタイルが当たっていないテキスト** | **整理の対象。ここが作業リスト** |
| **fontSize の分布** | スケールを何段にするかの材料 |
| **存在するのに使われていないスタイル** | 消していいスタイルの候補 |
| 除外したフレーム | 数え漏れ・数えすぎの確認 |

## このプラグインが行わないこと

- **Figma への書き込み**（一切しません。選択範囲も変えません）
- ネットワーク通信

## 使い方

1. Figma **デスクトップアプリ**で対象ファイルを開く
2. `Plugins → Development → Import plugin from manifest…` でこのフォルダの `manifest.json` を選ぶ
3. レイヤーパネルで対象の最上位フレームを選ぶ
   - `Screens/Mobile`（`525:2371`）
   - `Screens/Display`（`525:3394`）
   - `admin`（`525:5184`）
   - `Shift` で複数選択できます
4. `調べる（変更なし）` を押す
5. `JSONをコピー` で結果を保存する

## 件数の数え方（重要）

**インスタンスは、メインコンポーネントまでたどって1回だけ数えます。**

同じヘッダーが10画面に置かれていても、**カウントは1**です。スペーシングのプラグインと同じ挙動で、理由も同じです。

- スタイルを当てるのは**メインコンポーネント側**（インスタンスに当てると上書きになり、他に伝わらない）
- つまり件数は「画面に何回出るか」ではなく、**「何箇所直せば終わるか」**を表します

作業量の見積もりとしては、こちらのほうが正確です。

## 「混在」と出た場合

1つのテキストノードの中で、部分的に別のスタイルやサイズが使われています（一部だけ太字にしている、など）。

プラグインは**勝手に代表値を選びません。** node ID を出すので、Figma で開いて確認してください。意図的なものなら放置して構いません。

## 除外しているもの

スペーシング作業と同じリストを使っています。基準を作り直していません。

- 救済問題（`Mobile/Screen/Repechage/*`、`Display/Screen/Repechage/*`）
- iOS ステータスバー（`Mobile/System/Status Bar`、`475:8171`）
- Display の早押し画面（`Display/Screen/Buzzer/*`、フェーズ2）
