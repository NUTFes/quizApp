# 画面・要件確定 policy

> 2026-07-20 大幅更新: ゲーム形式が確定(**勝ち残り × 移動形式**)し、アプリの最少要件が
> 「回答機能なしの表示進行アプリ」に縮小された。旧S/M/A/R表は全項目を再評価済み。
> 旧版の推奨案(スマホで回答する前提)は履歴としてgit/旧表に残るが、正はこのファイルの現行版。

## 確定したゲーム形式(2026-07-20)

- **勝ち残り × 移動形式**: 会場を**2×2の4エリア**に分割し、各エリアが選択肢に対応。参加者は正解だと思う選択肢のエリアへ**物理的に移動**して回答する
- **回答の収集・正誤判定・脱落管理はアプリの外(人力運営)**。アプリは一切関与しない
- **早押しの自動判定はやらない**。早押し風の問題は「MCの読み上げに合わせて問題文を順々に表示する」演出機能で代替する

## アプリの役割(最少要件)

| 画面 | 役割 |
|---|---|
| モニタ | 主役。問題文(順次表示対応)・選択肢を**会場と同じ2×2配置**で表示・正答ハイライト・(推奨)移動締切タイマー |
| 管理者 | 進行操作(問題表示/文の送り/正答表示/リセット)+スプシ同期 |
| スマホ | ✅ **作る(2026-07-20決定・N1)**。会場規模的にモニタだけでは見えない人が出るため。内容は**モニタのread-onlyミラー**(問題文・順次表示・選択肢とエリアの対応・タイマー)。ボタン等の操作要素はゼロ |

スマホ画面は「見るだけ」なので、**回答API・参加者登録・ログインは引き続き存在しない**。QRを読んでページを開くだけ(localStorageも使わない)。リロード・途中参加は SSE接続時の `state` 受信で自動復帰(R6)。

## 新たに決めること(次の要決定リスト)

| # | 項目 | 推奨案 |
|---|---|---|
| N1 | スマホ画面(read-onlyミラー)を作るか | ✅ **作る(2026-07-20決定)**。会場規模的にモニタだけでは全員に見えないため。同時接続=参加人数分に戻るので、想定人数の確定(R5)と負荷試験(インフラI5)が必須タスクに復活 |
| N2 | 問題文の順次表示の制御方式 | ✅ **手動送りで確定(2026-07-22)**。早押しは「読み上げに合わせて `/` まで表示」+「裏方が管理画面を操作」と決まったため、裏方がボタンで1区切りずつ送る。→ `POST /api/admin/advance-text` と state の `revealedSegments` を採用 |
| N3 | 移動締切タイマー | ✅ **入れる。30秒固定で確定(2026-07-22)**。表示あり・早めのカットなし。0になっても自動遷移せず裏方が操作(D2)。問題ごとの上書きは任意で残す(デフォルト30) |
| N4 | 順次表示の区切り記法 | ✅ **`/` で確定(2026-07-22)**。スプシtext列に `/` を入れ、その位置で区切って配列化 |
| N5 | 形式ごとのエリア対応 | ✅ **確定(2026-07-22)**: 4択=2×2の4エリア。2択(あるなし)・○×=**ステージに対して左右**の2エリア(ラフは上下だったので要修正) |

## 追加の確定事項(2026-07-22 ワイヤーフレーム確定ヒアリング)

| # | 項目 | 決定 |
|---|---|---|
| W1 | 早押しの表示範囲 | **モニタのみ**に問題文を順次表示。スマホには早押しの問題文を出さない(手元で読めると早押しが成立しないため)。→ API・データ設計policyの「配信の出し分け(3宛先)」参照 |
| W2 | 正解演出(パチンコ風) | 企画側が動画を制作、アプリは**再生するだけ**。v1は正答フェーズ突入で自動再生、タイミング調整が要れば管理者ボタンを追加。動画は静的アセット(API配信しない) |
| W3 | アンケート | Google Form(メアド不要)。アプリは**リンク/QRを置くだけ**、集計はアプリ外。**クイズ終了後(finished)のみ表示**(冒頭に出すと離脱するため)。URLはフロントのビルド時環境変数を基本とする |
| W4 | 途中参加QR | モニタ**右上に固定表示**(静的URL、API不要) |
| W5 | 敗者復活 | **アプリ運用しない**(会場+Google Form+紙で人力)。約200人参加中、敗者復活は100〜150人想定 |
| W6 | 当日オペ体制 | 司会は紙のみ確認、**裏方1人が管理画面を操作**。管理画面は情報局員が使うので使いやすさ優先 |
| W7 | 待機画面 | モニタに「まもなく始まります」等の表示(waitingフェーズの表示内容) |
