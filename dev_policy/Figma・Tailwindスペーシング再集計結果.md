## 2. 集計ルール

- Auto Layoutのpadding、Item spacing / gap、Web実装の`padding` / `margin` / `gap`に相当する余白を対象とした
- 固定サイズ、文字、角丸、線、色、影、絶対配置の装飾座標は対象外とした
- 同じコンポーネント定義は複数画面にあっても1件とした
- 画面直下のフレームやセクションは、その都度1件とした
- 同じノードでも方向が異なる指定は別件とした
- node IDと指定方向で重複を除外した
- px値はFigmaの値をそのまま記録した
