# dev_policy — 「あとは開発するだけ」に到達するための方針集

このフォルダは、クイズアプリ開発を始める前に **決めておくべきこと・作っておくべきもの** を項目別にまとめたもの。
各ファイルは「方針(推奨案)」+「開発開始前にやるTODO」の構成になっている。

## 進め方ワークツリー(何を先に決め、何を並行できるか)

読む順(上の表)と、**実際に決めていく順**は別物。依存関係で描くと以下のようになる。
`═` が付いている枠同士は**お互いを待たずに並行で進められる**。矢印の先は「これが終わらないと始められない」もの。

```
【STEP 0】今日から並行で始められる3つ(お互いに依存なし)
│
├═ (a) 会場ネットワーク・公開方法の確認     → インフラ・デプロイ_policy の TODO 前半
│      ※コードと無関係だが外部調整で一番時間がかかる。今すぐ連絡だけ投げておく
│
├═ (b) 画面・要件の確定ミーティング         → 画面・要件確定_policy + MTG議題シート
│      ※最初にゲームルールの型(G1)を確定 → あとは推奨案に○×を付けるだけ
│
└═ (c) 技術スタックの確定                   → 技術スタック_policy
       ※メンバーの経験アンケート → 採否決定。(b)と同じ会でまとめてやってもよい

【STEP 1】(b)(c) が終わったら ── ここもお互い並行できる
│
├═ (d) API・データ設計                      → API・データ設計_policy
│      ← (b)画面が決まらないと必要なデータが決まらない
│      ← (c)スタックが決まらないと書き方が決まらない
│
└═ (e) リポジトリ基盤づくり                 → フォルダ構成 / 開発環境 / Git運用・CI_policy
       ← (c)スタックだけ決まれば着手できる((d)を待たなくてよい)
       │ 中身の順番はこう:
       ├── 1. リポジトリ作成 + フォルダスケルトン
       ├── 2. Docker + mise(`mise run up` で Hello World が動くまで)
       ├── 3. main保護 + CI + PR/Issueテンプレート
       └── 4. メンバー全員の環境構築 & PR練習(1人1回)
           ※メンバーはこの間、入門教材で学習期間にする

【STEP 2】(d)(e) が両方終わったら
│
└── (f) タスク起票・アサイン                → タスク分割・進め方_policy
       (d)のAPI仕様があるから初心者向けタスクまで具体化でき、
       (e)の環境があるから全員が今日から手を動かせる
       ═══ ここが「あとは開発するだけ」ライン ═══

【STEP 2以降・開発と並行】
│
└═ (g) 本番デプロイ準備                     → インフラ・デプロイ_policy の TODO 後半
       ← (a)の確認結果が出てから。開発を止めずに裏で進められる
```

### 要するに

1. **今日やる**: (a)の連絡を投げる+(b)(c)を決めるミーティングを設定する(1回の会で両方いける)
2. **ミーティング後**: まとめ役(+経験者)が (d) と (e) を並行で進める。メンバーは学習+環境構築
3. **(d)(e)完了 = 開発開始**。以降 (g) を裏で進める

ボトルネックになりやすいのは **(a)=返事待ち** と **(d)(e)=まとめ役の作業時間**。
(a)は待ち時間なので最初に投げる、(d)(e)は経験者がいれば片方を任せて並行化する、が時短のコツ。

## 「あとは開発するだけ」の定義(ゴールチェックリスト)

- [ ] 画面ごとの表示要素・遷移が確定している(未決事項ゼロ)
- [ ] 技術スタックが決まり、理由も説明できる
- [ ] API仕様書(エンドポイント+WSイベント一覧)が書かれ、フロントはモック、バックは仕様書だけで並行開発できる
- [ ] DBのテーブル定義が書かれている
- [ ] リポジトリが作られ、`git clone` → `mise run up` だけで全員の手元でアプリが起動する
- [ ] main ブランチが保護され、PR + CI が回る
- [ ] 最初の2週間分のタスクが Issue 化され、難易度ラベルが付いている
- [ ] 本番サーバーでの公開方法(URL/ドメイン)の目処が立っている
