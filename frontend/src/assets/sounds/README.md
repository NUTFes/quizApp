# 効果音

このディレクトリの `.mp3` は、管理者PCで鳴らす効果音です。Safariでも同じファイルを再生できるよう、形式はMP3に統一します。

## 現在のファイル（プレースホルダ）

現在の5ファイルは、実際の効果音が決まるまで使う**同一内容の約1秒の無音MP3**です。ファイル名を変えずに、それぞれ次の本番素材へ差し替えてください。

| ファイル        | 用途                     | 再生方法 |
| --------------- | ------------------------ | -------- |
| `deden.mp3`     | 出題前の「デデン」       | 1回      |
| `tick-tock.mp3` | 回答中のチックタック     | ループ   |
| `drumroll.mp3`  | 正答発表前のドラムロール | ループ   |
| `tada.mp3`      | 正解時の「タダーン」     | 1回      |
| `chime.mp3`     | 区切りのチャイム         | 1回      |

### 出典・ライセンス

- 出典: [DLHTX/BTAwake `Resources/1-second-of-silence.mp3`](https://github.com/DLHTX/BTAwake/blob/main/Resources/1-second-of-silence.mp3)
- ライセンス: MIT（出典リポジトリのREADMEに記載）
- 変更内容: 同じファイルを用途別の5ファイル名へ複製。音声内容の加工はしていません。

本番素材へ差し替えるときは、公開リポジトリで再配布できるライセンスかを確認し、この節を新しい出典・作者・ライセンス・加工内容に更新してください。
